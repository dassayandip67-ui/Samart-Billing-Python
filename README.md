Smart Billing & Profit Calculator

A beginner Python project that generates a simple retail bill and calculates sales, GST, and profit.

Project Overview

Small retailers need to calculate product costs, selling prices, discounts, taxes, and profits accurately.

This project demonstrates how Python fundamentals can be applied to a simplified billing scenario.

Features

- Collects customer and product details.
- Calculates total product cost.
- discounted sales.
- Calculates GST based on a user-provided rate.
- Calculates the final bill amount.
- Calculates profit and profit margin.
- Generates a simple customer ID.
- Extracts the domain from an email address.
- Displays a formatted billing report.

Technologies Used

- Python
- Visual Studio Code

Python Concepts Practised

- String indexing and slicing
- String methods

How to Run

1. Install Python on your computer.

2. Download or clone this repository.

3. Open the project folder in Visual Studio Code.

4. Run the following command in the terminal:
   
   "python smart_billing.py"

5. Enter the requested customer, product, pricing, discount, and GST details.

Sample Calculation

For 10 notebooks:

- Cost price per unit: ₹40
- Selling price per unit: ₹60
- Total discount: ₹50 or 8.33%
- GST rate: 5%

Expected results:

- Total cost: ₹400
- GST amount: ₹27.50

Limitations

This is an educational project, not a production-ready billing application.

It currently handles one product per bill, uses a simplified tax calculation, and does not include inventory management, persistent storage, or other business expenses.
